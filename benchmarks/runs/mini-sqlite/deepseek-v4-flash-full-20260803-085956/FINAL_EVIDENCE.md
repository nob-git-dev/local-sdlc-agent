## Harness findings during this run

- Large artifacts frequently caused malformed JSON or Markdown-fenced output;
  atomic proposition-sized calls were substantially more reliable.
- Two calls exceeded the 16,384-token context by a small margin; later calls
  used a fixed input margin.
- Artifact lint initially treated dataclass fields as unknown `self`
  attributes. The harness was generalized with Python AST analysis and its full
  regression suite passed.
- A read-only parser probe containing SQL text was conservatively classified as
  a database write. The probe was replaced with a side-effect-free test command
  instead of bypassing the safety decision.
